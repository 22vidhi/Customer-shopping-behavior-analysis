📌 Overview

This is a complete End-to-End Data Analytics Project where I analyze customer shopping patterns using Python, PostgreSQL, SQL, and Power BI.
The goal of the project is to identify revenue drivers, customer behavior trends, discount impact, product performance, and actionable insights for business decision-making.

🚀 Project Workflow

This project follows a full data analytics pipeline:

Data Collection (CSV)

Data Cleaning & EDA in Python (Pandas, NumPy)

Data Modeling & Storage in PostgreSQL

Advanced SQL Analysis

Power BI Dashboard creation (Visualization layer)

Insights & Conclusion
